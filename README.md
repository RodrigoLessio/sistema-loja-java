# Sistema Loja Java

Projeto desenvolvido em Java com foco em Programação Orientada a Objetos.

## Funcionalidades

- Cadastro de produtos
- Cadastro de clientes
- Criação de pedidos
- Adição de múltiplos produtos em um pedido
- Consulta de produtos
- Consulta de clientes
- Consulta de pedidos

## Conceitos utilizados

- Classes e Objetos
- Encapsulamento
- Construtores
- Métodos
- ArrayList
- Composição entre objetos
- Organização em pacotes
- Estruturas de repetição
- Estruturas condicionais

## Estrutura do projeto

```
model/
├── Cliente.java
├── Produto.java
├── ItemPedido.java
└── Pedido.java

service/
└── Loja.java

Main.java
```
